# Forgejo delivery binding

Machine authority: [`registry.json`](registry.json). Portable procedure: shared `forgejo-delivery-loop` Skill selected through `.agents/`.

The registry binds bettor-specific loop identities, artifacts, receipts, and local Forgejo delivery routes. It does not redefine the shared procedure, store credentials, or prove a current Forgejo session. Live origin and credential canaries remain separately evidenced.
