# Composition presets

Presets are named starting points for project initialization. They select a coherent baseline but do not bypass dependency resolution, proof or Human Admit.

Typical modes include:

- consumer-side core with immutable MCP clients;
- embedded core with local runtime/proof components;
- domain bundles such as wiki research or code truth;
- Arena owner tooling.

A preset is expanded into requirements, resolved, rendered into a temporary tree and verified before apply. Host trust, MCP approval, network permissions and secrets remain human-owned.
