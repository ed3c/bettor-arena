# Traversal proof receipts

This directory contains the established loop-level traversal receipts produced by `proof_workflow/`.

These receipts remain useful migration/provenance evidence, but module release validity is keyed by the module-closure subjects in [`../module-proof/`](../module-proof/). Per-run outputs are excluded or represented by bounded hashes according to the proof contract.

Use `proof_workflow/README.md` for evidence semantics and `python3 scripts/arena_proof.py check` for module-level aggregation.
