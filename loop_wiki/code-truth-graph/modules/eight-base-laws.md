# CTG eight-base landing

## B1 Rules/context

`AGENTS.md` + `CLAUDE.md`; missing context is a broken harness, not empty context.

## B2 Settings/authorization

`trigger.sh`/`run.sh`, stdin EOF, fresh absolute output, bundle containment, pinned tool profiles, minimal subprocess environment.

## B3 Lifecycle/observation

Caller-owned outputs plus local `logs/` and `anti/`; transient paths never become durable artifact references.

## B4 Route discovery

`ROUTES.md` and `.agents/agents/verifier.md`; routes list capabilities and state edges, not hidden orchestration.

## B5 Specialization

`ctg-domain-profile@1.0.0` selects bounded extractors/invariants. ix owns domain profiles and redacted live evidence.

## B6 Independent verification

`verify.sh`, `selftest.sh`, `portability.sh`, proof receipt, and behavioral control. The control keeps portable
packet, verifier, relocation, trusted-local, MCP inline carrier, live PROD/device, and Human-admit assurance
states separate. Offline executable axes require an unmodified green plus a byte-guarded planted red; live
PROD/device and Human admission remain named `NOT_EXERCISED`, never inherited from an offline green.

## B7 Goal contract

`PROMPT.md` fixes target, success, claim boundary and stop-loss.

## B8 State ledger

`PLAN.md` records append-only trajectory and Human edges. Runtime output never self-admits an invariant.
