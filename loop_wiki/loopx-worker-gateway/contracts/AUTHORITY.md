# Contract authority ceiling

The protocol transports observations only.

```text
request   = proposal to execute one exact subject
adapter   = static host contract and visibility ceiling
event     = externally observed process/filesystem fact
receipt   = subject-bound observation package
```

None of these documents may contain or imply canonical LoopX state, Gate PASS, Human Admit, durable-memory admission, promotion, rollback, merge, credential value or private chain-of-thought.
