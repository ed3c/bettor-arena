## Stable vocabulary

- **adapter manifest**: static host contract and observability ceiling; not live evidence.
- **Worker request**: exact subject, Skill/context digests, workspace lease and typed argv proposal.
- **Worker event**: gateway-observed process/filesystem fact; never private reasoning or state authority.
- **Worker receipt**: subject-bound execution observation; `OBSERVED_SUCCESS` is not Gate `PASS`.
- **white-box reference**: source-visible Harness reference, not open model weights and not runtime admission.
- **gray-box**: only externally observable/documented events may be recorded; hidden calls stay unknown.

## Authority

```text
Strategy proposes
Worker executes
Gateway observes
Gates decide
LoopX reducer commits
Human admits
```

No adapter, model, fixture, memory store or UI may collapse these roles.
