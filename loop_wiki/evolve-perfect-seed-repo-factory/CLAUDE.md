# Passive context — perfect-seed repo factory

- Process one packet and one repo output per round.
- Use only physical DR/GCR/repo/grill-me sources; hidden chat memory is not input.
- Preserve evidence, claims, unknowns, decisions, call plan, call results, and
  lineage as separate records.
- Twenty local deterministic calls are not twenty external model/tool calls.
- Do not overwrite an output or mutate a source repo.
- A green verifier yields a validated candidate, never automatic seed admission.
- Human admission is the terminal edge.
