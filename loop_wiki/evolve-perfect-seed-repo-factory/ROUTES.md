# Routes — perfect-seed repo factory

## Stateful workflow

| node              | actor                 | input                     | validator                         | pass edge         | failure edge           |
| ----------------- | --------------------- | ------------------------- | --------------------------------- | ----------------- | ---------------------- |
| F0 FAST-PREFLIGHT | mechanical script     | factory + repo template   | lineage/format/lint/type receipt  | M0                | preflight-repair       |
| M0 MATCH          | `seed-factory-router` | typed source packet       | `src/contracts.ts`                | G1                | packet-repair          |
| G1 GENERATE-IR    | mechanical script     | admitted source           | nonzero evidence and hash binding | V1                | source-intake          |
| V1 VALIDATE-IR    | mechanical script     | reduced IR                | public behavior tests             | G2                | implementation-repair  |
| G2 GENERATE-REPO  | mechanical script     | template + IR             | generated repo tests              | V2                | discard-partial-output |
| V2 VALIDATE-REPO  | mechanical script     | generated repo            | fast quality + full repo verifier | R1                | repo-repair            |
| R1 RECORD-OBSERVE | mechanical script     | route result + stats      | baseline/trend gates              | H1                | drift-review           |
| H1 ADMIT          | human                 | hashes, tests, comparison | human judgment                    | admitted/rejected | return to named node   |

## Source routes

| source kind | bounded interpretation                                      | extra authority                               |
| ----------- | ----------------------------------------------------------- | --------------------------------------------- |
| `dr`        | source-linked research narrative                            | none; external facts remain candidate         |
| `gcr`       | conversation intent and proposed mechanisms                 | none; speaker claims are not truth by default |
| `repo`      | read-only bounded file manifest and excerpts                | no mutation                                   |
| `grill-me`  | explicit questions, answers, constraints, and taste signals | no claim that interview is complete           |

## Actor boundary

- `main-session` owns integration and human-facing synthesis.
- `mechanical-script` owns schemas, hashes, counts, DAG execution, and tests.
- `.agents/agents/seed-factory-router.md` returns one route only.
- `.agents/skills/perfect-seed-domain/SKILL.md` owns local terminology.
- External research/judgment is not performed by this loop.
- Human owns lifecycle seed admission and architecture replacement decisions.

## Prompt/context ownership

- Raw task contract: `PROMPT.md`.
- Stable semantic context: `modules/semantic-truth-context.md`.
- Iteration context: `_engine-run/exchange-context.<packet_id>.md`, generated by
  `trigger.sh`.
- Emergent context: packet field, explicit path or `N/A-none`.
- Judgment logic: `verify.sh`, `selftest.sh`, typed source validators, and human admit.

## Route result

`trigger.sh` writes `packets/outbox/route-result.<packet_id>.json` with packet,
source kind, output, build status, validator status, next edge, and human gate.
It never writes an admitted seed decision.

`trigger.sh` records `build_exit`, `fast_quality_exit`, `operator_exit`, and
`validator_exit`. A nonzero earlier stage leaves later stages unexecuted. The
fast quality result is local preflight evidence, not an asynchronous Code
Quality or Production Use axis receipt.
