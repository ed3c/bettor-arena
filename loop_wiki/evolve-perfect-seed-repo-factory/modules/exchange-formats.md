# Exchange formats

## Input packet

`perfect-seed-input@1.0.0` requires packet id/state, source kind/path, task,
fixed and emergent context, and `required_before_seed_admit`. Only admitted
packets may materialize a repo.

## Schema replay

`src/migrate_packet.ts` is the only current migration edge:
`perfect-seed-input@0.1.0` → `perfect-seed-input@1.0.0`. It adds explicit
context and human-gate fields but does not auto-admit a draft packet.

## Result formats

- source/IR/lineage schemas are versioned in their files;
- call plan contains exactly twenty calls and dependency ids;
- call results are JSONL with input/output SHA-256;
- route result is generated by `trigger.sh` and ends at human-required;
- `perfect-seed-fast-quality-receipt@1.0.0` records gate-input hashes,
  per-stage commands, exit codes, elapsed time, stdout/stderr tails, and
  fail-fast `not_run` stages; its claim boundary is preflight-only;
- baseline updates require a reviewed/admitted governance packet.

Paths are passed as structured argv. No packet contains a shell command.
