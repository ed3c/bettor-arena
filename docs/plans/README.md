# Execution plans

`docs/plans/<date>-<topic>/` stores implementation plans and as-run ledgers.

A plan should separate:

- target contract;
- current evidence;
- ordered slices;
- acceptance conditions;
- negative controls;
- human-owned admits;
- remaining `NOT_IMPLEMENTED` / `NOT_EXERCISED`.

After execution, record what actually ran. Do not rewrite the original plan to make the result appear pre-determined.
